# Hero slideshow pictures

Drop pictures in here as `01.jpg`, `02.jpg`, `03.jpg` … and they become the slideshow in the
hero, in that order. `.png` works too. Nothing else needs editing — `index.html` asks for each
number in turn and stops at the first one that is missing, so the count is however many files
are here (up to 12).

**Shape.** The frame takes its proportions from `01`, so nothing is ever cropped — whatever
shape you export is the shape the slot becomes. **4:5 keeps the hero balanced** (1200 × 1500 is
a good export); 9:16 also works but makes the hero about 200px taller on a desktop screen.
Keep every picture the same shape as `01`, or the later ones will be cropped to match it.

**What works in them.** These sit beside the hero headline, so pictures that carry their own
big headline end up arguing with it. Product shots — screens, the board, a phone in a workshop
— read better than title cards.

**If this folder is empty** the hand-built order card (`#124`) keeps the slot, which is what
the site ships with today. That is deliberate: a checkout without these pictures is still a
finished page.
